Project title: Artificial intelligence
Project description: showcases the different ways to make AI, from rule based, machine learning and deep learning, gives info about the 3 main types of ML. 
With the purses of introducing the user to these ways and for them to know more about AI in general.

Features: The website contains a rule based chat bot, and interactive elements to explain different types and ways (clicking to see definition and sections being hidden).

How to use: when opening the website, the user can is met with the definition of AI, then chooses which way to see. 
If the user chooses machine learning, they have 3 options to choose from, and in each, they are met with a chat bot,
where they choose a question from the options and the bot answers.
In deep learning, the user can click once to see the definition, and click twice to turn it back to its original shape.
whenever a user chooses a different way to check out, the last one they chose gets hidden.

Technologies: HTML, CSS and JavaScript.

Credits: ChatGBT (for info) and W3schools.
